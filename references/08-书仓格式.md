# 书仓格式规范

本文件是 `scripts/novel.py` 与技能工作流共同遵守的公共契约。修改字段、路径或命名规则时，同步更新脚本、模板与本文件，并在 `CHANGELOG.md` 记录。

## 目录

```
<书仓根>/
├── .novel/
│   ├── config.json
│   ├── state.json
│   └── 变更记录.md
├── 00-契约.md
├── 01-世界书/
│   ├── 人物.md
│   ├── 势力与地点.md
│   ├── 规则与力量体系.md
│   └── 时间线.md
├── 02-大纲/
│   ├── 总纲.md
│   └── 卷NN.md
├── 03-正文/
│   └── 第NNN章_章名.md
├── 04-草稿区/
│   ├── 灵感.md
│   ├── 导入/
│   └── 第NNN章/

│       └── 审读报告.md

```

## 三区与修改边界

| 区 | 路径 | 规则 |
| --- | --- | --- |
| 真源区 | `00-契约.md`、`01-世界书/`、`02-大纲/`、`05-账本/` | 只在作者确认后更新；改动要做影响分析 |
| 草稿区 | `04-草稿区/` | 自由试错，可多稿并存；不进导出 |
| 定稿区 | `03-正文/` | 定稿后只读；修订走 retcon |
| 派生区 | `.novel/state.json`、`06-导出/` | 可随时删除重建，不是事实源 |

「候选」与「已确认」必须可区分：草稿区内容、审读发现项、待沉淀事实一律视为候选；正文、契约、账本中已写入的内容视为事实。

## 命名规则

- 章文件：`第NNN章_章名.md`，章号**全书连续**，至少 3 位十进制，不足补零（`第001章`）。禁止用「本卷最大章号」推断章数。
- 卷文件：`卷NN.md`；卷目录若使用子目录则为 `卷NN/`。
- 草稿目录：`04-草稿区/第NNN章/`；稿件 `稿N.md`（N 从 1 递增，不覆盖旧稿）；暂存稿 `稿N.起草中.md`，不计入待审稿。
- 章名中的非法字符（`/ \ : * ? " < > |`）替换为全角或删除。
- 所有文件 UTF-8 无 BOM，LF 或 CRLF 均可。

## frontmatter

正文、草稿、契约使用 YAML frontmatter（仅键值，无嵌套）：

```yaml
---
标题: 第十分钟
章号: 12
稿次: 2
状态: 待审        # 起草中 / 待审 / 待裁决 / 已定稿
细纲版本: v1
汉字数: 0         # 由脚本写入，勿手填
创建时间: 2026-11-11
---
```

`count` 与 `check` 会排除 frontmatter 与 HTML 注释（`<!-- -->`）。汉字数统计 Unicode 汉字区间 `\u3400-\u4dbf`、`\u4e00-\u9fff`、`\uf900-\ufaff`，含章标题、不含 frontmatter 与注释。字符数与非空白字符数单独给出，报告时须标明口径。

## config.json

```json
{
  "title": "长夜将明",
  "genre": "都市异能",
  "platform": "起点",
  "pov": "第三人称有限视角",
  "min_words": 1600,
  "target_words": 2000,
  "max_words": 2400,
  "created": "2026-11-11",
  "format_version": 1
}
```

`min_words ≤ target_words ≤ max_words`，均为正整数。缺字段时 `check` 报「篇幅未约定」，不擅自套默认值。

## state.json（派生）

```json
{
  "format_version": 1,
  "last_finalized_chapter": 12,
  "total_han": 24510,
  "updated": "2026-11-11T22:10:00",
  "note": "派生缓存，冲突时以文件为准，可用 rebuild 重建"
}
```

由 `status` / `settle` / `rebuild` 从实际文件重算，不保存会话状态、不保存待办队列。删除后不影响任何创作数据。

## 账本条目

- 事实编号 `F-<章号><序号>`，例 `F-0121`；修订编号 `RC-<序号>`。
- 伏笔编号 `F001` 起顺序递增，与事实编号格式不同以免混淆；台账含「未回收 / 已回收」两表。
- 人物状态表按章一行，列为固定六项（章 / 人物 / 位置 / 身体与能力状态 / 知情范围 / 关系变化 / 持有物）。
- 本书记忆条目以 `[决定]` `[写法]` `[禁区]` 开头，改结论时更新原条并注明日期，不删旧记录。

## 导出

`export` 只读取 `03-正文/` 中章号连续的已定稿文件，按章号排序拼接，输出到 `06-导出/`：

- `书名_全本.txt` / `.md`，或 `书名_卷NN.txt` / `.md`；
- 目标文件已存在时默认拒绝覆盖（`--force` 才覆盖，并先备份为 `.bak`）；
- 输出附一份 `来源清单.md`：每章文件名、汉字数、定稿时间；
- 不含草稿、审读报告、账本、候选事实。

## 路径安全

脚本只接受书仓根内的相对路径；拒绝盘符、`..` 逃逸、绝对路径、保留设备名与指向仓外的符号链接。`init` 不覆盖已有文件，`settle` 用临时文件 + `os.replace` 原子替换，失败时保留现场。

## Git 建议

书仓可独立建 Git 仓库，建议提交粒度：

- `design: 作品契约确认`
- `design: 卷01细纲`
- `ch: 第012章 定稿`
- `retcon: RC-001 回溯次数修订`

`.gitignore` 可排除 `06-导出/` 与 `.novel/state.json`（两者都可重建）。提交失败不等于入档失败，不要重复执行 `settle`。

## 版本与迁移

`format_version = 1`。未来字段变更须：给出旧数据夹具、迁移与回退说明、验证步骤；预览差异与执行迁移分开，并各自取得作者确认。浏览、检查与升级预览都不自动改写书仓。
