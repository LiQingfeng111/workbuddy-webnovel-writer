# 去 AI 味与文风

「AI 味」不是句子太长，而是模型特有的解释欲、对称结构和情绪标签。定稿前单独过一遍这份清单，命中项记入审读报告的「文风与表达」维度。

## 一、高频 AI 腔清单

| 类型 | 典型表现 | 处理 |
| --- | --- | --- |
| 抽象概括 | 「这一刻，他终于明白了什么是责任」「命运的齿轮开始转动」 | 删掉，改成具体动作或留白 |
| 情绪直述 | 「他感到一阵莫名的恐惧」「心中五味杂陈」 | 换成身体反应、动作、环境细节 |
| 三段排比 | 「不是……不是……而是……」「有的……有的……还有的……」 | 拆成两句或只留一处 |
| 连接词过密 | 「然而」「因此」「与此同时」「不仅如此」「总而言之」 | 中文叙事多靠意合，直接删 |
| 万能比喻 | 「仿佛……一般」「如同……般」「似乎……」连着出现 | 全书控制密度，删除无信息量的 |
| 段末金句 | 每段结尾都要升华一句 | 只在关键章末保留钩子，其余删 |
| 解释欲 | 写完一个动作，立刻解释这个动作说明了什么 | 让读者自己得出，删解释句 |
| 对称收束 | 开头写雨，结尾必写「雨还在下」 | 用一次就够，第二次换写法 |
| 信息复述 | 人物对话里互相复述读者已知设定 | 改成冲突或潜台词 |
| 标签化描写 | 「眼神中闪过一丝复杂的情绪」 | 写具体：他把手里的杯子放下了 |
| 程度词堆叠 | 「极其」「非常」「深深」「彻底」 | 大多数可直接删 |
| 均匀节奏 | 每段长度接近、每章结构一致 | 短句穿插、段落长短交替 |

## 二、改写手法

1. **以物代人**：不写「他很紧张」，写「他第三次去摸口袋里的钥匙，还在」。
2. **动作承担信息**：不写「他知道陈叔在说谎」，写「他没接话，把椅子往后挪了半寸」。
3. **潜台词**：让对话双方各说各的，别把冲突解释清楚。
4. **删掉第一句和最后一句**：模型起草的段落常以概括开头、以升华结尾，删掉后往往更干净。
5. **控制视角**：第三人称有限视角下，不写他人内心、不写主角看不到的画面、不写「殊不知」。
6. **具体名词替换抽象名词**：「某种力量」→「左手掌心那道烫痕」。
7. **留白**：钩子靠未回答的问题，不靠「而这一切，才刚刚开始」。

### 对照示例

> 改前：他感到一阵莫名的恐惧，仿佛有什么未知的力量正在暗处窥视着他。然而，他深知自己不能退缩，因为这不仅关系到姐姐的真相，更关系到整个城市的安危。命运的齿轮，终于开始转动。
>
> 改后：楼道灯灭了。他停在第三级台阶上，没敢再往上抬脚。手机屏幕亮着，姐姐最后那条短信还停在半句：「别再用第——」。他把手机扣进口袋，转身下楼，走了两步又停住，重新抬头往黑里看了一眼。

改后没有解释情绪、没有总结、没有排比，但信息量更大：环境、恐惧、短信伏笔、犹豫与反转都在。

## 三、网文质感

- **开篇三行内给钩子或异常**，不要先铺世界观。
- **每章至少一次微兑现**：一个信息、一次小胜、一句有意思的对白、一个关系推进。
- **对话要带摩擦**：两人目标不同才有戏；纯信息传递的对话改成叙述或删掉。
- **爽点要有前置成本**：先立规则与代价，再让主角在规则内取胜，否则读者不买账。
- **章末钩子别写成总结**：停在动作、物件或未答的话上。
- **少用生僻字与长定语从句**：手机竖屏阅读，一句超过 40 字就该考虑断句。

## 四、平台排版

- 段落 1–4 行，避免大块文字；对话独立成段；
- 章标题格式统一（`第NNN章 章名`），与文件名一致；
- 中文全角标点；省略号用「……」，破折号用「——」；
- 不写 Markdown 语法到正文（加粗、列表、分隔线、代码块），导出后再按平台要求处理；
- 不出现「本章完」「未完待续」「TODO」「（此处补充）」等字样；`check` 会拦下占位符。

## 五、执行方式

1. 起草时先不管文风，按细纲把内容写足；
2. 审读阶段单跑一遍本清单，把命中项作为发现项列出（附原文片段）；
3. 修改时另存新稿，只处理作者同意处置的项，不顺手重写全章；
4. 换稿后重跑 `count` 与 `check`，旧字数与旧审读结论作废。

去 AI 味的判断标准很简单：**把一段话里所有「解释、总结、升华」删掉后，故事还成立吗？** 成立就该删。
