# 立项与作品契约

## 目标

把一个模糊的想法（「想写本都市异能」）收敛成一份**可验收的作品契约**：之后每一章写什么、不许写什么、写多少字，都有明确依据。契约是全书第一份真源文件，后续世界书、大纲、账本都不得与它冲突。

## 四步流程

### 1. 灵感盘点

先让作者自由说，不急着结构化。记录：想写的画面、喜欢的作品、想避开的套路、有没有已经想好的人物或结局。把这些信息写进 `04-草稿区/灵感.md`，**标为候选**，不直接进真源区。

一次只问 3–5 个问题，不要一口气发一张二十项的表格。信息不足时给出合理默认并标注「待作者确认」，不要编造作者的偏好。

### 2. 题材定位

从 `07-题材速查.md` 找到主题材（可融合 1–2 个副题材），明确三件事：

- **核心承诺**：读者点开这本书，最想反复获得的那一种体验是什么。
- **开篇任务**：前 3 章必须交付什么（主角亮相、金手指生效、第一个冲突、第一次微兑现）。
- **节奏单位**：一章一个小兑现、几章一个中段高潮、一卷一个大结算。

题材融合时，指定主题材承担节奏，副题材只提供设定或爽点，避免两套承诺互相打架。

### 3. 契约定稿

运行 `init` 生成书仓后，逐项与作者确认，写入 `00-契约.md`。必填字段：

| 字段 | 说明 | 反例 |
| --- | --- | --- |
| 书名 / 一句话卖点 | 一句话能说清主角 + 处境 + 钩子 | 「一个少年的成长故事」 |
| 题材与融合 | 主题材、副题材、各自职责 | 罗列五个标签 |
| 目标平台与读者 | 决定节奏、章长、尺度 | 不填 |
| 叙事人称与时态 | 第三人称有限 / 第一人称 / 多 POV 切换规则 | 中途随意换人称 |
| 基调与情绪承诺 | 燃 / 轻松 / 压抑 / 悬疑，及其比例 | 「有爽有虐」 |
| 读者承诺 | 前 3 章、每章、每卷分别交付什么 | 只有一句「会好看」 |
| 禁区 | 明确不写的情节、设定、尺度、角色结局 | 「别写崩」 |
| 篇幅约定 | 下限 / 目标 / 上限（正整数，下限 ≤ 目标 ≤ 上限） | 「两千左右」 |
| 核心冲突 | 谁想要什么、谁挡着、代价是什么 | 只有世界观没有冲突 |
| 主角目标与代价 | 目标、动机、能力边界、必须付出的东西 | 无代价的金手指 |
| 结局方向 | 已知 / 待定；若已知，写出终局画面 | 强行定死导致中期僵化 |

篇幅约定单独放在三级标题「章节篇幅」下，只写三项数值，供 `check` 与脚本读取：

```markdown
### 章节篇幅
- 下限汉字数: 1600
- 目标汉字数: 2000
- 上限汉字数: 2400
```

其他说明（例如「大高潮章可放宽」）写在相邻小节，不要混进这三项；放宽须由作者当场决定并留痕，脚本不会自动放宽。

### 4. 验收

- 契约不含 `TODO`、`待补`、`XXX` 等占位符。
- 篇幅三项为正整数且顺序合法。
- 作者明确确认后，才把契约从「候选」转为真源；随后才能开始世界书与大纲。
- 契约变更：改完必须重新核对世界书、大纲、已定稿正文的影响，用 `retcon --note` 留痕，旧章审读中的篇幅证据作废，需要重跑 `check`。

## 常见坑

1. **承诺与节奏不匹配**：主打「轻松日常」却按「生死危机」开篇，前三章就把读者筛掉。
2. **禁区写得太抽象**：「不要虐主」无法执行；写成「主角不因误会失去同伴超过一章」才可检查。
3. **金手指没有代价与边界**：中期必然战力崩坏，补设定只能靠 retcon。
4. **篇幅没约定**：审读时无法判断超长超短，只能凭感觉，字数纪律立刻失效。
5. **一次问太多**：作者被问卷劝退，契约变成 AI 单方面脑补。

## 交付物

- `00-契约.md`（真源，作者已确认）
- `04-草稿区/灵感.md`（候选，保留原始想法）
- `.novel/config.json` 中的书名、题材、平台、篇幅数值与契约一致
